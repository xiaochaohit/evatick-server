# 使用双层 CLI 同时提供稳定语义与完整覆盖

AKShare 当前公开约 1,094 个名称，逐一人工设计和维护独立命令会制造过大的命令面，而只提供少量精选命令又无法满足完整覆盖。CLI 因此采用双层结构：常用金融数据通过稳定的语义命令提供，全部受支持的 AKShare 公共数据函数从首版起通过自动生成、可发现、可描述、可调用的原始接口提供；原始接口明确继承上游兼容性风险。全量原始接口是首版交付范围，不按领域或使用频率分期。

## Consequences

语义命令必须维护统一参数、字段和错误契约；原始接口必须自动生成接口清单与参数模式，且不能把上游函数的变化伪装成稳定契约。全量覆盖以 `akshare` 根命名空间直接暴露的公共数据函数为边界，不承诺包内未导出的内部函数。新增或升级 AKShare 版本时，覆盖检查必须阻止任何公共数据函数被静默遗漏。

`set_token`、`get_token` 和 `pro_api` 明确排除：前两者读写明文凭据并与环境变量凭据策略冲突，后者返回不可直接序列化的 Python 客户端对象而非数据。注册表生成报告必须列出每个排除项及理由，排除清单之外的公共数据函数不得静默遗漏。

ADR 0030 后来将跨版本兼容承诺明确限定为命令路径；参数和返回字段可以随 CLI 与绑定数据提供方的升级调整。
