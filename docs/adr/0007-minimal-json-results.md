# 成功结果直接输出数据本体

大模型已经知道自己调用的命令，重复输出命令、稳定性、上游函数、版本、参数、成功标记和记录数量会浪费上下文。成功调用因此直接输出返回数据的 JSON 表示，不增加统一信封；失败使用非零退出码，并在标准错误中输出只包含错误代码和可行动消息的最小 JSON。

稳定语义命令使用由 CLI 维护的英文 `snake_case` 字段；自动生成的上游命令保留 AKShare 原始字段，包括可能存在的中文字段。全量生成器不得机械翻译字段，因为错译和名称碰撞会改变数据含义。版本和环境信息由 `market-cli version` 与 `market-cli doctor` 单独提供。
