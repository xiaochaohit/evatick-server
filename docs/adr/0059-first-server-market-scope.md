# 首个服务端版本限定为中国内地股票与指数

首个 Market Server 版本只支持中国内地股票与指数。股票范围为上海证券交易所、深圳证券交易所和北京证券交易所的在市 A 股，包括主板、科创板、创业板和北交所股票；不包括 B 股、港股、美股、ETF、基金及其他证券类型。

指数范围为上海证券交易所、深圳证券交易所或中证指数有限公司发布，并且至少有一个已启用数据提供方声明支持至少一种首版能力的指数。指数与股票共用统一标的目录，通过标的类型区分；目录同时保留股票交易场所和指数发布机构，不能用笼统的“中国市场”字段替代这些身份信息。

未来增加其他市场或标的类型时，通过新增标的目录来源、数据提供方插件和能力覆盖扩展，不改变首版金融标的的稳定身份。首版范围不构成对以后市场命令路径或领域模型的限制。
