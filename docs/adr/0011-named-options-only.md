# 所有调用参数使用具名选项

CLI 只面向大模型，位置参数依赖顺序且容易在多个代码、日期和周期之间产生歧义。稳定命令和自动生成命令因此都使用 `--symbol`、`--period`、`--start-date` 等具名选项，不定义位置参数；Python 下划线参数确定性地映射为连字符选项。

## Consequences

必填项必须在 `--help` 中显式标记。类型优先来自注解、其次来自默认值，无法推断时按字符串处理；真正的布尔值使用正反开关，列表使用重复选项，字典和嵌套结构可使用 `--args-json`。`--args-json` 与独立参数不能混用，帮助需同时展示 CLI 名称和原始 Python 参数名。
