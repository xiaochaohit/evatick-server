# 0062 Adopt the EVA product identity

## Status

Accepted.

## Decision

The product brand is EVA. The service command is `evatickd`, while internal
workspace packages use the `@evatick/*` scope.

HTTP payload schemas use the `eva.*` namespace and problem types use `urn:eva`.
The browser administration surface is named EVA 管理中心 and uses the EVA mark.

## Consequences

Process output, deployment examples, API credentials, documentation, and
user-facing pages use EVA consistently.
