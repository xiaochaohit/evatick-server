# 数据调用使用工作进程和 120 秒硬超时

绑定版本的 AKShare 包含大量未显式设置请求超时的网络调用，单靠传递参数无法防止命令永久挂起。数据命令由轻量监督进程启动独立工作进程执行，并设置默认 120 秒总预算；预算包含 AKShare 加载、网络调用、退避和重试，调用者可用 `--timeout` 显式覆盖。

## Consequences

监督进程在预算耗尽时必须终止工作进程并返回可重试的超时错误。临时错误只有在剩余预算内才允许重试；帮助、目录查询和缓存命中不启动工作进程。进程间结果传输需兼容 DataFrame、字典、列表和标量，并避免在写入 stdout 前产生部分结果。
