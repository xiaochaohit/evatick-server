# 股票日线默认使用新浪财经

2026 年 8 月对三只不同市场股票的相同近期窗口进行实测时，AKShare 东方财富 `stock_zh_a_hist` 三次全部发生可重试网络失败，而新浪 `stock_zh_a_daily` 三次全部成功。稳定命令 `market-cli stock bars` 因此改为日线首选新浪；只有新浪发生连接失败、超时或可重试 HTTP 错误时才降级东方财富。周线和月线继续使用东方财富，因为新浪接口只提供日线，不能进行不等价替代。每条记录继续通过 `_market_cli_source` 标明实际来源，两个上游命令本身保持原样。此决定取代 ADR 0055 的数据源优先级。
