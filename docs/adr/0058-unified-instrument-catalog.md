# 股票与指数共用统一标的目录

服务端维护数据提供方无关的标的目录，以稳定 `instrument_id` 唯一引用金融标的，并将各数据提供方的代码保存为带来源和有效期的标识映射。首版只收录股票和指数；两者共享目录和搜索、解析机制，通过标的类型区分，而不是建立两套主数据系统。

“全部支持标的”定义为至少有一个已启用数据提供方声明支持至少一种能力的规范标的集合。数据提供方插件负责提供可追溯的标的快照或增量及能力覆盖；无法枚举完整清单时必须暴露覆盖未知或不完整状态，不得把提供方返回的临时代码列表冒充完整目录。退市或失效标的保留稳定身份和有效期，不做破坏性删除。

标的搜索根据规范名称、标识和别名返回真实目录候选；标的解析再结合市场、交易场所、标的类型和所需能力确定唯一标的，或者明确返回歧义及未找到状态。大模型或向量检索只能对目录候选做召回或重排，不得生成或直接充当规范 `instrument_id`。所有行情请求在领域边界内使用规范 `instrument_id`，仅由数据提供方适配层转换为提供方代码。
