# 使用精简领域分类并显式定义替代数据

AKShare 的内部模块按实现和历史演进组织，直接暴露约三十个顶层模块会削弱命令的可发现性。CLI 使用精简的金融领域分类，将股票扩展、基本面以及 AKShare 上游交易日历函数归入 `stock`、不同外汇模块归入 `fx`、期货衍生模块归入 `futures`，并将空气质量、日出时间、电影与艺人、人口迁徙、财富排行、NLP、研究型数据、银行监管处罚、游戏热榜和汽车销量归入 `alternative`。稳定交易日历契约后来由 ADR 0025 提升至独立的 `calendar` 领域。

## Consequences

注册表必须维护上游模块到用户领域的确定性映射。`alternative` 的文本帮助和机器可读帮助必须列出当前子领域、用途和示例，不能只描述为“其他数据”；新增长尾类别时必须同步更新该说明。
